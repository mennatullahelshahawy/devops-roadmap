## 📊 Server Performance Stats
https://roadmap.sh/projects/server-stats

🧾 What this script does
This script shows basic info about your system:
- CPU usage
- Memory usage (used & free)
- Disk usage
- Top 5 processes using CPU
- Top 5 processes using memory

📌 Example Output:
```
==== System Monitoring ====

CPU Usage:
...

Memory Usage:
In Use: 45%
Free: 55%

Disk Usage:
...

Top 5 CPU usage processes:
...

Top 5 Memory usage processes:
...
```

## Log Archive Tool
https://roadmap.sh/projects/log-archive-tool

🧾 What this script does
- Takes a log directory as input
- Creates an archives folder
- Compresses all logs into a .tar.gz file
- Adds a timestamp to the archive name

📌 Example
```
./archive.sh /var/log
```

This will create something like:
```
archives/logs_archive_20260504_153000.tar.gz
```
